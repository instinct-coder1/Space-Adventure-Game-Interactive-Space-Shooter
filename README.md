# Space-Adventure-Game-Interactive-Space-Shooter
building game space Adventure game
 browser-based mini project built with **HTML, CSS and vanilla JavaScript**. Pilot a spaceship, avoid enemy ships, shoot them down, and try to beat your score.

## Features

- Welcome screen with mission introduction and controls
- Three difficulty levels: Rookie, Pilot and Ace
- Keyboard movement (arrow keys or WASD)
- Spacebar laser shooting
- Enemies spawn and move automatically
- Bullet/enemy and player/enemy collision detection
- Score, lives and wave indicators
- Increasing difficulty as the score rises
- Pause/resume, game-over screen and restart
- Responsive layout; no backend or installation required

## Run the project

1. Download and unzip the project folder.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in a browser.
   - Recommended: use the VS Code **Live Server** extension and click **Go Live**.
   - Or simply double-click `index.html`.

The game runs locally. An internet connection is only needed to load the optional Google Fonts; the game itself does not need a server or database.

## Controls

| Key | Action |
|---|---|
| Arrow keys / WASD | Move spaceship |
| Spacebar | Fire lasers |
| P | Pause / resume |
